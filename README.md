# GC-Content-Calculator 🧬📊

A Python tool to analyze DNA stability for Biotechnology research.

## What it does
- Calculates GC% content of any DNA sequence
- Counts G and C nucleotides
- Predicts DNA stability (High GC = More Stable)
- Clean, fast, and CET-exam relevant

## Why it matters
- GC Content is asked in PU-CET Genetics
- High GC = Stronger DNA, important for PCR & lab work
- Used in real bioinformatics pipelines

python gc.py
